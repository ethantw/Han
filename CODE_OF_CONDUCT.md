# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc] as its
code of conduct. By participating in this project — opening issues,
sending pull requests, commenting, or representing the project in
public spaces — you agree to abide by its terms.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Scope

The Code applies within all project spaces — the GitHub repository
(issues, pull requests, discussions, commit history), the
[manual site](https://hanzi.pro), and any official communication
channel (email, social media) representing the project.

## Reporting

To report a concern, contact the maintainer privately at
[ethantw@me.com](mailto:ethantw@me.com). Reports will be handled
with discretion; reporter identity is kept confidential by default.

## Enforcement

Maintainers follow the Contributor Covenant's
[Enforcement Guidelines][eg] when responding to reports — the same
four-tier ladder (correction・warning・temporary ban・permanent
ban) defined in the linked document.

[eg]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines
