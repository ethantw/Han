# han.css v4 安装（简体中文入口）

这个 Skill 会替用户的网站或应用安装并配置 han.css v4。流程：

1. **先检测、后提问**——检查项目的框架、打包器、语言标记、既有字体与
   排版设置，能检测的不问；
2. **最多三个问题**——网站语言、黑体或宋体、要不要传承字形 webfont；
   其余一律用推荐默认值，并把每个决定与理由记录在一个入库的配置文件里；
3. **先修 `lang` 标记**——han.css 的一切功能都挂在正确的语言标记上，
   缺了它整套排版静默失效；
4. **生成安装码与配置文件**，跑一次验证清单（字体、着重号、挤压悬挂、
   混排间隙、引号惯例……）。

## 执行方式

**权威版本是英文版**：读取并完整遵循同目录家族的
`skills/han-setup/SKILL.md`（canonical，English）。本文件只是语言入口，
不重复任何技术细节——变量名、默认值、包路径一律以英文版与它指定的
API reference 为准，两者若有出入以后者为准。

执行时：

- 与用户的对话（提问、说明、验证清单）用**简体中文**；
- 生成的配置文件内的说明注释用简体中文，但所有标识符、属性名、值、
  文件名照英文版规范原样输出，不翻译；
- 英文版要求「做了要告诉用户为什么」的地方（`lang` 修正、竖排镜射、
  许可义务），用简体中文说明。
