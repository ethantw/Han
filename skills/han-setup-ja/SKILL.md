## 実行方法

（canonical, English）を読み、完全にそれに従うこと。本ファイルは言語
エントリに過ぎず、技術的詳細は一切重複させない——変数名・デフォルト
値・パッケージパスは英語版とそれが指す API reference を正とし、
食い違えば後者が勝つ。

- ユーザーとの対話（質問・説明・検証チェックリスト）は**日本語**で；

  翻訳しない；
- 英語版がユーザーへの理由説明を求める箇所は、すべて日本語で説明する。
