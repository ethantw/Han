# han.css v4 安裝（繁體中文入口）

## 執行方式

**權威版本是英文版**：讀取並完整遵循同目錄家族的
`skills/han-setup/SKILL.md`（canonical，English）。本檔只是語言入口，
不重複任何技術細節——變數名、預設值、套件路徑一律以英文版與它指定的
API reference 為準，兩者若有出入以後者為準。

執行時：

- 與用戶的對話（提問、說明、驗證清單）用**繁體中文**；
- 產生的設定檔內的說明註解用繁體中文，但所有識別字、屬性名、值、
  檔名照英文版規範原樣輸出，不翻譯；
- 英文版要求向用戶說明理由的地方，一律用繁體中文說明。
