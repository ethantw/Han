# han.css v4 安裝（繁體中文入口）

這個 Skill 會替用戶的網站或應用程式安裝並設定 han.css v4。流程：

1. **先偵測、後提問**——檢查專案的框架、打包器、語言標記、既有字體與
   排版設定，能偵測的不問；
2. **最多三個問題**——網站語言、黑體或明體、要不要傳承字形 webfont；
   其餘一律用建議預設值，並把每個決定與理由記錄在一個入庫的設定檔裡；
3. **先修 `lang` 標記**——han.css 的一切功能都掛在正確的語言標記上，
   缺了它整套排版靜默失效；
4. **產生安裝碼與設定檔**，跑一次驗證清單（字體、著重號、擠壓懸掛、
   混排間隙、引號慣例……）。

## 執行方式

**權威版本是英文版**：讀取並完整遵循同目錄家族的
`skills/han-setup/SKILL.md`（canonical，English）。本檔只是語言入口，
不重複任何技術細節——變數名、預設值、套件路徑一律以英文版與它指定的
API reference 為準，兩者若有出入以後者為準。

執行時：

- 與用戶的對話（提問、說明、驗證清單）用**繁體中文**；
- 產生的設定檔內的說明註解用繁體中文，但所有識別字、屬性名、值、
  檔名照英文版規範原樣輸出，不翻譯；
- 英文版要求「做了要告訴用戶為什麼」的地方（`lang` 修正、直排鏡射、
  授權義務），用繁體中文說明。
