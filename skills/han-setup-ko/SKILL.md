# han.css v4 설치(한국어 진입점)

이 Skill은 사용자의 사이트나 앱에 han.css v4를 설치·설정한다. 흐름:

1. **감지 먼저, 질문은 나중에**——프레임워크·번들러·`lang` 속성·기존
   폰트와 조판 설정을 조사하고, 감지할 수 있는 것은 묻지 않는다;
2. **질문은 최대 세 개**——사이트 언어, 고딕이냐 명조냐, 전승자형
   웹폰트 사용 여부. 나머지는 권장 기본값을 적용하고, 각 결정과
   이유를 커밋되는 설정 파일에 기록한다;
3. **먼저 `lang`부터 고친다**——han.css의 모든 기능은 올바른 언어
   태그에 걸려 있으며, 빠지면 전체가 조용히 무효가 된다;
4. **설치 코드와 설정 파일을 생성**하고 검증 체크리스트(폰트, 강조점,
   압축·내어쓰기, 혼합 조판 간격, 따옴표 관례……)를 한 바퀴 돈다.

## 실행 방법

**정본은 영어판**: 같은 skills 패밀리의 `skills/han-setup/SKILL.md`
(canonical, English)를 읽고 완전히 그에 따를 것. 이 파일은 언어
진입점일 뿐 기술적 세부를 일절 중복하지 않는다——변수명·기본값·
패키지 경로는 영어판과 그것이 가리키는 API reference를 기준으로
하며, 어긋나면 후자가 이긴다.

실행 시:

- 사용자와의 대화(질문·설명·검증 체크리스트)는 **한국어**로;
- 생성하는 설정 파일의 설명 주석은 한국어로 쓰되, 식별자·속성명·
  값·파일명은 영어판 규범 그대로 출력하고 번역하지 않는다;
- 영어판이 "실행했으면 이유를 사용자에게 알리라"고 하는 대목(`lang`
  수정, 세로쓰기 미러, 라이선스 의무)은 한국어로 설명한다.
