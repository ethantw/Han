# dash-fuse 重編：從二十五秒的獨腳戲，回到一次修正 — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓 station② 的破折號底圖停止表演，改為陳述一件事——破折號本來是
斷的，han.css 把它接上了。做法是砍掉主循環（四次重逢＋撐不住＋鬆手）、砍掉
接合後的閃黑，把幅度收回真實值，只留「等待期的極低幅呼吸 → 一次 520ms 的
熔接 → 從此接著」。

**Architecture:** 改動集中在 `manual/public/home/dash-fuse.css` 的
keyframes 與 `[data-play]` 規則；幾何管線（`--df-fuse` → `--df-a1`／
`--df-b0` → rect transform）、SVG 座標系、`dash-fuse.js` 的 armed／play
蓋章時機一概不動。`--df-ink` 整支退場。

## 二、診斷

### 1. 尷尬的根源是前提，不是拍點

這是 `z-index: -1`、對比 7%／12% 的**裝飾底圖**，卻被編了 25 秒、四幕、
擬人化的獨腳戲。裝飾物只會被眼角看見；眼角能分辨的只有「有沒有在動」與
「亮不亮」，分辨不了「猶豫、退半步、停半秒」。所有細膩的編舞在感知上都塌
縮成一句「那邊有東西一直在動」——既不安靜，也沒說話，這就是尷尬。

繼續調拍點只會得到第六個版本。

### 2. 底圖大部分時間在演文案的反面

25s 裡有 **14.4s 破折號是壞的**（0–10.63s 的嘗試期＋20.38–25s 的漏氣鬆
手），只有 9.75s 是接好的。而這一欄的文案正在說「中間斷開的破折號⋯⋯精準
為讀者拂偏歸正」。**論據圖多數時間站在論點的對面**，而且每 25 秒把已經修好
的東西再拆一次——那是 bug 的動畫，不是 fix 的動畫。

### 3. 幅度在說謊

真實的病是西文領頭字體 emdash 兩端縮進造成的 **0.1em 中縫**（檔頭自述：
Georgia 0.05em、Helvetica Neue 0.13em）。動畫為了讓遠處看得見，把 fuse 探到
-2.6，縫張到 **0.36em ＝ 真實值的 3.6 倍**。這張圖全部的說服力建立在「它是
真的」，誇張化把紀錄片變成漫畫。

### 4.「整根變黑」不好看的四個具體理由

- **它換掉了自己的語彙。** 檔頭寫「面淡、邊清——低對比的可讀性來自輪廓而不
  是面積」，而閃黑是 `fill` 與 `stroke` **同時** mix 到深灰，那一下整條線變
  成實心深灰棒（`dash-10p7s`）。輪廓語言換成面積語言。
- **它跳出了底圖層的色階。** 同柱漢字永遠 7%，破折號一下衝到接近正文墨色，
  讀起來像「一個 UI 元件亮起來了」，不像墨。
- **它不是閃，是亮著。** 250ms 竄上、4.5s **ease-in** 淡回（ease-in 前段幾乎
  不掉）——實測接上後 2.4s 仍近全深。一輪裡約 4 秒有一根深色重槓貼在正文左
  緣，當分隔線用。
- **它跟本檔的自述矛盾。** 檔頭：「動畫語彙同 MarkDiagram：一個事實一個
  0→1、520ms ease-out、**無高光無彈跳**」。閃黑就是高光。

## 三、設計方向

### 方案 A（推薦）：一次修正

等待期維持極低幅的呼吸（讀者還在讀上一段，柱以斷開態現身、微微動著，證明
它活著）；`data-play` 一蓋，**一次 520ms ease-out 熔接，從此接著，不再斷
開**。沒有循環、沒有閃色。

- 對得上文案：圖上永遠停在「已修正」，跟這一欄的主張同向。
- 對得上本檔自述的 MarkDiagram 語彙（一個事實一個 0→1）。
- 尷尬消失的原因是**沒有表演**了——它只剩一個事實。
- 代價：滾過去之後就沒戲看了。這正是裝飾底圖該有的分寸；真正的「戲」在同站
  台的鉛字盤（.LeadForme），一站有一個主角就夠。

### 方案 B：底噪呼吸（保守）

保留循環但降到感知門檻以下：週期收到 8–10s、fuse 夾在 `[0, 1]`（縫最大 ＝
真實值）、刪掉閃色、刪掉「撐不住」那一幕（接上之後只是輕輕呼吸，縫從不真正
再斷開）。適合「還是想要它一直活著」的口味，但仍有第 2 點的矛盾（縫會鬆
開），只是縮小到不刺眼。

### 方案 C：捲動驅動（有趣但有前置查證）

`animation-timeline: view()`——縫的合攏由讀者自己的捲動推進，捲到欄中央剛好
接上。時機永遠不會錯，因為時機是讀者給的；也完全免掉「等鉛字落完」那套 JS
時序。**前置**：`animation-timeline` 的 Baseline 年份要照本 repo 慣例查證後
註記，且不支援時必須退回已接合終態（與 reduced-motion 同一條 fallback）。
建議列為 A 落地後的獨立提案，不混在這一輪。

**推薦：A**，並把「閃黑」處理成下節的 A-ink。

### 閃色（`--df-ink`）四選一

| | 作法 | 評 |
|---|---|---|
| **A-ink（推薦）** | 整支刪掉 | 縫消失本身就是事件，不需要再打一盞燈。最省，也最符合「無高光」 |
| B-ink | 只動 `stroke`，`fill` 不動，幅度減半，300ms 上、600ms 下 | 保住「面淡邊清」，像壓實了一分 |
| C-ink | 接縫處局部吃墨（沿柱的 gradient 峰值在 820，300ms 收） | 最像墨的語彙，但要多一層 SVG gradient／mask，複雜度不對稱 |
| D-ink | `stroke-width` 0.5→0.8 再回，200ms | 印刷語彙（壓印吃墨），一行搞定，可作為 A-ink 的加料 |

### Task 7（追加，owner 拍板 2026-07-31）: hover 重播

不自動循環的唯一代價是「滾過去就沒戲」。補法：游標停在 `.PunctFix` 上就重播
一次斷開→接合。重播由讀者要求，不是頁面自作主張，所以「圖與文案同向」的原則
沒破。

- [x] **Step 1:** 新增 `@keyframes df-replay`——前 12%（90ms）仍是接合態當猶
  豫窗（`.PunctFix` 是整欄寬，滑鼠掃過容易掠過，擦一下就重播會變成新的煩躁
  源），13% 瞬斷（斷開本來就是突發的），其後 520ms ease-out 接回。
- [x] **Step 2:** `.PunctFix:hover &[data-play]` 在 `animation` 清單**追加**
  `df-replay`，而不是換掉 `df-fuse`。理由寫在規則旁：animation-name 清單一
  變動，換上來的動畫就會從頭播——若 hover 時把 `df-fuse` 換成 `df-replay`，
  游標一移開 `df-fuse` 被重新指派，就會冒出讀者沒要求的第二次重播。
- [x] **Step 3:** `@media (hover: hover)` gate——觸控裝置沒有 hover，`:hover`
  會黏在最後點過的元素上變成隨機重播。功能偵測而非 UA 嗅探（web-style.md）。
- [x] **Step 4:** JS 一行不動，維持本檔「幾何與動畫全在 CSS」的契約。

## 第二輪（owner feedback，2026-07-31 同日）

三點回饋，全數落地：**① 接合後還是要變色**（色調交我定）、**② 不夠有衝擊，

### 色調的取捨（我的決定）

峰值仍是 `--palette-ink-grey`（亮色 graphite／暗色 silver——暗色主題的站台底
本來就是 graphite，方向自動反過來）。**走墨、不走光**：這是印刷的頁面，綠色
accent 或任何提亮都會讀成「UI 元件亮起」。三處刻意與舊版不同：

- **邊走滿、面只走六成**（`--df-ink * 100%` on stroke、`* 60%` on fill）——舊
  版兩者同時竄滿，整條線從「線」變成「棒」，把本檔「面淡、邊清」的語彙換掉。
- **150ms 上、340ms 下**——舊版 250ms 上、4.5s ease-in 下，實測接上後 2.4s
  仍近全深，那不是閃，是亮著。
- **淡回只回到 .35，不回 0**——接上之後這根線比原來實一分，永久留著。不循環
  也留得下痕跡：晚點回頭看，看得出它是被修過的。`--df-ink` 的
  `initial-value` 因此設為 `.35`，reduced-motion／無 JS 落在同一根線上。

### 衝擊怎麼給（一個幾何事實）

墨跡外緣 727／913 固定，縫一旦合上（fuse ≥ 1）兩截只是**重疊**，畫面完全看不
出來——**位移過衝在這副幾何裡是隱形的**。所以「猛然」寫在別的地方：90ms 的
段長、ease-in 的加速，以及接觸瞬間 `stroke-width` 由 .5 壓到 .9 再彈回
（新增 `--df-press`，印刷的壓印吃墨語彙）。

- **首播 1150ms**：靠近（0→.82，420ms ease-out）→ 彈開（→.55，160ms ease-in）
