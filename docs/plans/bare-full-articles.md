## 三之前・prose 排列法編排（owner 追加，2026-08-05）

h1–h6／ol／p／blockquote 不只「出現」，要**踩到 `src/css/prose.css`
實際處理的每一種排列**（連續標題收合、標題接段落、縮排家族、巢狀）。
編排取材自三篇內容本身，不造假結構：

| prose.css 規則 | 編排落點 |
|---|---|
| 連續標題收合（`hN:has(+ hN+1…)` → a-block-end／b-block-start） | 報眉式進場：h1 篇題**緊接** h2 首個 crosshead（emperor 篇天然如此）；要目區 h2→h3→h4 三連 |
| 標題接 blockquote | h1 之後直接導語 blockquote（三篇原稿的固定形制） |
| 標題接 ol／ul | h3「協定核心條款」+ ol（earth-moon）；h4 篇目 + ul |
| `blockquote` 縮排＋**巢狀減半**（`blockquote blockquote`） | 三體賀電引宣命：賀電 blockquote 內再引宣命一句——引用中的引用，取材自 emperor 結尾 |
| `blockquote` 楷體換字＋內部 `dfn/i/var` 還原（`--han-prose-fonts`） | 導語 blockquote 裡保留一個 `<dfn>`（koi8 篇的「亂碼」定義句） |
| `figure` 縮排＋`blockquote figure` 還原 | **figure > table + figcaption**：萬歲光速延遲表裝進 figure（表格＋圖說一次到位） |
| `ol/ul` 縮排＋巢狀清單 | 協定條款 ol 內第三條掛子項 ul（附件細目） |
| `.poem-like` | **宣命唱詞式**：emperor 的宣命句以 `.poem-like` 分行排——詔書體天然是詩型排列 |
| `p` justify＋首行縮排 | 全部正文段落 |

## 三之二・結構標註層（owner 追加）——虛線框＋元素標籤＋總開關

裸頁「零樣式」修訂為**兩態**：標註態（預設，教學用）與素態（一鍵關）。

1. **語意 block 元素的可視化**：`article` 用**虛線框＋ `::before` 元素名
   標籤**（如 `‹article›`）標出邊界；同招延伸到 `section`／`blockquote`
   ／`figure`／`ol`／`ul`／`dl`／`table`。技術約束：
   - **outline 不用 border**——outline 不佔盒模型，排版度量零污染
     （這頁展示的就是排版，標註不得改變它）；
   - `::before` 標籤 `position: absolute`（元素補 `position: relative`，
     皆零度量影響）；pseudo 不是子元素，不干擾 `:first-child`／`+`
     兄弟選擇器（prose 的連續標題規則照常）；
   - 各元素類別配不同淡色（`light-dark()`、跟 `color-scheme` 走），
     標籤字用等寬小字。
2. **導覽註記**：各段落合適處插 `<p><small>…</small></p>`，說明該處
   用了哪個模塊、哪些元素、什麼技巧（例：「本段的引用中引用示範
   `blockquote` 巢狀縮排減半——han-prose」）。註記樣式（縮小、退色、
   側線）同屬標註層。
3. **總開關**：`<label><input type="checkbox" id="…">顯示結構標註</label>`
   （預設勾選），標註層規則罩在 `:root:has(#chrome:checked)` 之下
   （web-style 的 dark-mode 同款 `:has()` 技巧）。**console 相關樣式
   （fixed 定位＋body 讓位）不入 gate**（owner 修訂，2026-08-05）：
   儀表板不是展品，素態關的是內容標註不是工具——console 常駐也順帶
   免去「素態下 fixed 疊層蓋住控制列、點不回來」的死角。取消勾選＝
   內容區零樣式素態。
4. **`<style>` 塊自我記錄**：檔頭註解列明「本頁唯一樣式表＝標註層＋
   console 讓位」，並註明素態即出廠 HTML。母 plan
   `bare-page-console-demo.md` 決策 §1 的「唯一一條 CSS」自此修訂為
   「唯一一張可整體關閉的標註層」。

## 三、語意元素補洞——三篇原文沒有的，用頁面自身區塊補

盤點：h1–h2、blockquote、q、cite、dfn、em、u/del/ins、ruby 三篇原文
（＋既有四分區）已覆蓋；**缺 h3–h6、dl、table、ol**（ol 由
earth-moon-aoe 的條款清單補進 article 內）。其餘不硬塞進新聞原文，
落在**非 article 區**：

| 元素 | 落點（每語言包同構） |
|---|---|
| h3／h4 | 「本期要目」改階層式：h2 要目 → **h3 分類**（宮廷典禮／科技考古／地月危機）→ **h4 篇目條** |
| h5／h6 | **刊頭資訊欄**（報紙本來就有的細字欄）：h4 發行資訊 → **h5 訂閱與轉載** → **h6 免責聲明**——真實報紙的巢狀小字，不是為塞而塞 |
| dl | 「本期數據」欄：宣命字數 467字／皇配名銜議事 31日／年號議事 19日／候補案 6件（1 件豆腐出局）——emperor 篇自帶的數據天生是 `<dl>` 料 |
| table | **萬歲光速延遲表**：月城 1.28秒／火星 18分40秒／木衛二 35分11秒／土星軌道群 1時12分／柯伊伯帶 5時17分——原文自帶的表格化數據，含數字對齊與漢西混排展示價值 |
| ol | earth-moon-aoe《地月共榮協定》核心條款三條（article 內，原文自有） |

h1–h6 全階核對：h1（各篇題）→ h2（篇內 crosshead ＋ 區塊題）→
h3／h4（要目階層）→ h5／h6（刊頭欄）。
