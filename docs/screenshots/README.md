# 版面實裝截圖

首頁各站在實作當下的畫面紀錄，二〇二六年七月。留著是為了回答
「這個設計當初長什麼樣」——程式改了，截圖不會跟著改，所以它們是
**歷史**，不是現況；與今日的頁面對不上是正常的，別拿來當驗收基準。

檔名前綴：

- `實裝-` 該站完工時的樣子（`站①` 語意、`站②` 字體排印、`站叄` 行的調整）
- `特寫-` 單一元素的近拍（雙專名號、ja 的 `<cite>`、ssSpecimen）
- `懸掛試寬-` 站叄懸掛對照的 measure 掃描過程，檔名即當時的 `max-inline-size`
- `範文擬稿-` 內容定稿前的全頁預覽

原本與《太陽中文報》的稿件放在同一個資料夾（那批稿現已獨立成
`hanzi.pro/taisol/`）。這些圖記錄的是 han.css 的排版結果而非報紙內容，
故歸此處。
