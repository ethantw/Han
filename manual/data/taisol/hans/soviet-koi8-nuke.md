# 谜底竟是一行乱码　苏联核弹封存三十载　解密者：磁碟没坏，是你的电脑太新

> 地球无核武协议十五年，最后一批苏联洲际飞弹迟迟无法拆除：封存磁碟完好，但所有人读出的都是乱码。谜底历时十五年才解开——问题不在磁碟，在于一套九十年前退场、已无人记得的苏联字符编码<dfn>KOI-8</dfn>；正确解读全程，耗时十七分钟。

【本报月球特派员　钱福兴　专电】

地球无核武协议签署已届第十五年，人类距离彻底废除核武的终点，却仍差着最后几枚锈迹斑斑的老物件。

问题不在政治，不在意愿，而在一批没有人看得懂的磁碟。

彼时冷战的遗产——苏联一九七〇、八〇年代部署的洲际飞弹群——至今仍带着原装的启动与关闭程序，封存在乌拉尔山以东某处的地下设施里。程序本身从未损毁，问题在于：没有任何人能读懂它们写了什么。

各国政府为此组建了一支史无前例的破译团队，成员横跨科技考古学家、精通多国语言的语言学者，乃至最新一代的人形语言学机器人。十五年来，这支队伍踏遍地球每一座存有冷战档案的地下库房，始终无功而返。症结始终是同一个：那些磁碟在现代考古电脑上解读出来的，是一片汉字与乱符交织的天书。

<q>一定是磁碟坏了，</q>一位不愿具名的科技考古学家在十年前的会议纪录中留下这句话，<q>才会把俄语程序显示成汉字。</q>

另一派学者则持截然相反的看法，并因此引发一场延烧十余年的学术笔战。以权慧晶教授为首的一派指出，苏联与共产中国之间的关系，或许远比史书记载的更为暧昧——彼此在意识形态上虽剑拔弩张，私下的技术交流是否完全断绝，史料从未给出明确答案。程序中掺入中文，或以汉字作为加密手段，并非全无可能。

（编按：此论点目前史学界尚无定论，然而中苏于一九六九年已爆发边境武装冲突，苏联更一度评估对中国发动核先制攻击，学界多数意见认为技术共享可能性极低。该争论至今仍是考古语言学界著名公案。）

上述争议，在上月以一种格外令人泄气的方式画下句点。

谜底不在磁碟，不在苏中秘密协议，而在一件所有人都忘了去想的事：编码。

破译组的年轻成员循尼亚・薛，在一次例行翻查二十世纪资讯工程文献时，无意间读到一份尘封九十年的技术备忘录，页首印着苏联标准委员会的红色徽章，内容涉及一套名为<code>KOI-8</code>的字元编码规范——专为西里尔字母设计，与当时西方通行的<abbr title="American Standard Code for Information Interchange" lang="en">ASCII</abbr>系统互不相容，彼此之间无一字母对应。

在此有必要向习惯了万码归一的现代读者稍作说明。所谓「<dfn>编码</dfn>」，是电脑将文字转化为数字讯号时所依据的对照表；而所谓「<dfn>乱码</dfn>」，是当一份文件用某套对照表写成，却被另一套对照表强行解读时，所产生的荒谬结果——正确的数字，对应到了<em>全然错误</em>的文字。这在今日听来匪夷所思，因为当代通行的Unicode标准已将地球上几乎所有文字系统收纳其中，任何装置读取任何文件，皆从同一张总表取字，乱码作为一种日常灾难，早已绝迹逾八十年。然而在二十世纪下半叶，各国、各系统、有时甚至各机构之间，各自维护着一套互不承认的编码规范，犹如语言相通却字母各异的平行文明。<q>当时美国的电脑，</q>循尼亚・薛在记者会上以平静得近乎残忍的语气说，<q>连『<i lang="de">Schrödinger</i>』这个名字，当时的电脑都无法完整显示——那个用来命名核子时代最著名思想实验的人。整个数位文明在当时其实是各说各话的。</q>

她随即补充，KOI-8及其同类编码，在距今约九十年前，已随着Unicode统一标准的全球普及而悄然退出历史舞台。近半个世纪以来，人工智慧模型的训练语料库中，这类格式的文本已稀少到可以忽略不计。

<q>连电脑也不行，</q>现场待机的人形语言学机器人EISO-2200补充道，措辞一如既往地精确而不带任何感情色彩，<q>相关训练资料量不足以令模型辨识这属于一种系统性的编码错误，而非真实的汉字内容。</q>

换言之：<strong>没有人读得懂，是因为所有人用的都是错误的钥匙</strong>。正确的解法，是以<code>KOI-8</code>格式重新读取磁碟，再转换为当代Unicode标准。整个过程耗时约<em>十七分钟</em>。而这个方法，在一百年前本是任何一名资讯工程学生入学第一周便会习得的常识——只是那门课，早已从所有大学的课纲里消失。

破译组事后表示，正确版本的程序以标准俄语写成，技术逻辑清晰，保存状态完好，并无任何损毁或加密迹象。

据悉，拆除作业将于下周正式启动。这批飞弹内部的<ruby>钚<rt>bù</rt></ruby>与铀-235，将统一移送至非洲超导电池联合工厂，降浓缩处理后制成民用储能电芯，首批成品预定免费配发予月球定居点及南极洲越冬站居民，作为取暖设备电源。

一个半世纪前凝固的末日预言，以这样的方式抵达它最终的去处：某户人家的暖气，在极夜里亮着。

循尼亚・薛离开记者台前，有人在人群中喊了一句：<q>那十五年呢？</q>

她停顿了一秒。

<q>那十五年，</q>她说，<q>是我们为不记得历史所付的<em>学费</em>。</q>

掌声没有响起。
