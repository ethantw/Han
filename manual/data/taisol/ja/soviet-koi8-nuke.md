# 謎は一行の文字化けだった　ソ連核弾頭封印三十年　解読者「磁気ディスクは壊れていない、あなたのコンピュータが新しすぎるのだ」

> 地球非核協定から十五年、最後のソ連大陸間弾道ミサイルはいまだ解体できずにいる。封印された磁気ディスクは無傷なのに、誰が読んでも文字化けしか出てこない。謎が解けるまでに十五年かかった――問題はディスクではなく、九十年前に歴史の舞台から消え、誰も覚えていないソ連の文字符号化規格<dfn>KOI-8</dfn>にあった。正確に解読するのに要した時間は、十七分だった。

【太陽新聞　月面特派員　錢福興　特電】

<cite>地球核兵器廃絶協定</cite>の締結から十五年。かつて核兵器を保有した各国は、すでに核燃料を研究機関へ移管し、深宇宙推進、原子炉研究、放射線医学に充てている。人類が核兵器の完全廃絶へ至るまでには、なお<ruby>錆<rt>さび</rt></ruby>の浮いた最後の数発が残っていた。

問題は政治でも意志でもなく、誰にも読めない磁気ディスクの一束にある。

かつての冷戦の<ruby>遺産<rt>いさん</rt></ruby>――ソ連が一九七〇年代から八〇年代にかけて配備した大陸間弾道ミサイル群――は今なお起動・停止手順を<ruby>搭載<rt>とうさい</rt></ruby>したまま、<ruby>ウラル山脈<rt>うらるさんみゃく</rt></ruby>の東のどこか、地下施設の奥に封印されている。手順そのものは損なわれていない。問題はただ一点：それが何を書いているのか、誰にもわからないことだ。

各国政府はそのために<ruby>前例<rt>ぜんれい</rt></ruby>のない解読チームを結成した。技術考古学者、多言語に精通する言語学者、さらには最新世代のヒューマノイド言語学ロボットまで、幅広い顔ぶれが揃った。十五年にわたり、このチームは地球上に存在する冷戦文書の地下保管庫をくまなく踏破したが、常に手ぶらで戻ってきた。<ruby>癥結<rt>ちょうけつ</rt></ruby>はいつも同じだった――現代の考古用コンピュータでディスクを読み出すと、漢字と意味不明な記号が入り混じった<ruby>天書<rt>てんしょ</rt></ruby>が現れるのだ。

<q>ディスクが壊れているに決まっている</q>と、匿名を希望した技術考古学者が十年前の会議記録に書き残している。<q>だからロシア語のプログラムが漢字で表示されるのだ</q>

対照的な見解を持つ別の学派はその言葉に真っ向から<ruby>反駁<rt>はんばく</rt></ruby>し、十余年にわたる学術論争の火蓋を切った。權慧晶教授を筆頭とする一派が指摘するのは、ソ連と共産中国の関係が、歴史書の記述よりはるかに<ruby>曖昧<rt>あいまい</rt></ruby>だった可能性だ――イデオロギー上は<ruby>剣呑<rt>けんのん</rt></ruby>な緊張関係にありながら、水面下での技術交流が完全に断絶していたかどうか、史料は明確な答えを与えていない。プログラムに中国語が<ruby>紛<rt>まじ</rt></ruby>れ込んでいること、あるいは漢字が暗号手段として使われていることは、まったくありえない話ではないというのだ。

（編注：この論点に関しては史学界でいまだ定説がない。しかし中ソは一九六九年に国境武力衝突を起こしており、ソ連は中国への核先制攻撃を一時検討していたとされる。学界の多数意見は技術共有の可能性を極めて低いと見ており、この論争は考古言語学の著名な未解決問題として今日も残っている。）

この論争は先月、ひどく<ruby>拍子抜け<rt>ひょうしぬけ</rt></ruby>のする形で幕を閉じた。

謎はディスクにも中ソ秘密協定にもなく、誰もが考えようとしなかった一点にあった――<ruby>符号化<rt>ふごうか</rt></ruby>、つまり文字エンコーディングの問題だ。

解読チームの若いメンバー、<ruby>循尼亞<rt>シューニャ</rt></ruby>・薛は、ある日の例行的な二十世紀情報工学文献の調査中、九十年間<ruby>眠<rt>ねむ</rt></ruby>り続けた一通の技術覚書を偶然目にした。表紙にはソ連標準委員会の赤い<ruby>徽章<rt>きしょう</rt></ruby>が押されており、内容は<code>KOI-8</code>と呼ばれる文字符号化規格に関するものだった――<ruby>キリル文字<rt>きりるもじ</rt></ruby>専用に設計されたこの規格は、当時の西側で普及していた<abbr title="American Standard Code for Information Interchange" lang="en">ASCII</abbr>システムと互換性がなく、一文字の対応もない。

ここで、万コードが一つに統一された現代に慣れた読者のために、少し補足しておく必要がある。<dfn>「エンコーディング」</dfn>とは、コンピュータが文字を数値信号に変換する際に参照する対応表のことだ。そして<dfn>「文字化け」</dfn>とは、ある対応表で書かれた文書を、別の対応表で強引に読み解こうとしたとき生じる<ruby>滑稽<rt>こっけい</rt></ruby>な結果である――正しい数値が、<em>まったく見当違いの文字</em>に対応してしまう。現代の感覚ではおよそ<ruby>信<rt>しん</rt></ruby>じがたい話だが、現在広く使われているUnicode規格は地球上のほぼすべての文字体系を収録しており、どの機器でどの文書を開いても同じ一覧表から文字を引くため、日常的な<ruby>惨事<rt>さんじ</rt></ruby>としての文字化けはすでに八十年以上前に<ruby>絶滅<rt>ぜつめつ</rt></ruby>している。しかし二十世紀後半には、国ごと、システムごと、時には機関ごとに、互いを認めない符号化規格が乱立していた。言語は通じるのにアルファベットが異なる並行文明のようなものだ。<q>当時のアメリカのコンピュータでは</q>と<ruby>循尼亞<rt>シューニャ</rt></ruby>・薛は記者会見で、穏やかでほとんど残酷なほどの口調で語った。<q>『<i lang="de">Schrödinger</i>』という名前さえ完全に表示できなかった――核の時代の最も有名な思考実験に名を冠した、あの人物の名前が。デジタル文明全体が、当時は互いに別の言葉を喋っていたのだ</q>

さらに彼女は付け加えた。<code>KOI-8</code>およびそれと同種の符号化規格は、今から約九十年前、Unicode統一標準が世界に普及するとともに、静かに歴史の舞台を降りた。この半世紀近く、人工知能モデルの訓練コーパスにおいて、こうした形式のテキストはほぼ無視できるほど希少になっている。

<q>コンピュータでも無理だった</q>と、その場に待機していたヒューマノイド言語学ロボットEISO-2200が、いつものように正確で感情を帯びない言葉で補った。<q>関連する訓練データが不十分なため、モデルはこれが系統的な符号化エラーであると認識できず、実際の漢字コンテンツだと判断してしまうのだ</q>

要するに、<strong>誰にも読めなかったのは、全員が間違った鍵を使っていたからだ。</strong>正しい解法は、<code>KOI-8</code>形式でディスクを再度読み込み、現代のUnicode規格に変換すること。全工程の所要時間は約<em>十七分</em>。そしてその方法は、百年前であれば情報工学を学ぶ学生なら入学第一週に習う常識だった――ただ、その授業が、あらゆる大学のカリキュラムから消えてずいぶん経つ。

解読チームはその後、正しいバージョンのプログラムは標準的なロシア語で書かれており、技術的な論理は明快で保存状態も完全、損傷も暗号化の<ruby>痕跡<rt>こんせき</rt></ruby>もまったくなかったと発表した。

伝えられるところによれば、解体作業は来週にも正式に開始される。これらのミサイルに搭載されたプルトニウムおよびウラン235は、アフリカの超伝導電池統合工廠に送られ、<ruby>減濃縮<rt>げんのうしゅく</rt></ruby>処理ののち民生用蓄電セルへと製造される。初回の製品は月面定住地および南極越冬基地の居住者に無償配布される予定で、暖房設備の電源として使われる。

一世紀半前に<ruby>凝固<rt>ぎょうこ</rt></ruby>した終末の予言は、こうして最終的な行き先に辿り着く。どこかの家の暖房として、極夜の中で灯り続ける。

<ruby>循尼亞<rt>シューニャ</rt></ruby>・薛が記者台を離れようとしたとき、人群の中から声が飛んだ。<q>じゃあ、その十五年は？</q>

彼女は一秒、間を置いた。

<q>あの十五年は</q>と彼女は言った、<q>歴史を忘れた代償として、我々が払った<em>授業料</em>だ</q>

拍手は起きなかった。
