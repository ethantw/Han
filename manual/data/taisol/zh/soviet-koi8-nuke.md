# 謎底竟是一行亂碼　<u>蘇聯</u>核彈封存三十載　解密者：磁碟沒壞，是你的電腦太新

> 地球無核武協議十五年，最後一批<u>蘇聯</u>洲際飛彈遲遲無法拆除：封存磁碟完好，但所有人讀出的都是亂碼。謎底歷時十五年才解開——問題不在磁碟，在於一套九十年前退場、已無人記得的<u>蘇聯</u>字符編碼<u><dfn>KOI-8</dfn></u>；正確解讀全程，耗時十七分鐘。

【本報月球特派員　<u>錢福興</u>　專電】

地球無核武協議簽署已屆第十五年，人類距離徹底廢除核武的終點，卻仍差著最後幾枚鏽跡斑斑的老物件。

問題不在政治，不在意願，而在一批沒有人看得懂的磁碟。

彼時<u>冷戰</u>的遺產——<u>蘇聯</u>一九七〇、八〇年代部署的洲際飛彈群——至今仍帶著原裝的啟動與關閉程序，封存在<u>烏拉爾山</u>以東某處的地下設施裡。程序本身從未損毀，問題在於：沒有任何人能讀懂它們寫了什麼。

各國政府為此組建了一支史無前例的破譯團隊，成員橫跨科技考古學家、精通多國語言的語言學者，乃至最新一代的人形語言學機器人。十五年來，這支隊伍踏遍<u>地球</u>每一座存有<u>冷戰</u>檔案的地下庫房，始終無功而返。癥結始終是同一個：那些磁碟在現代考古電腦上解讀出來的，是一片漢字與亂符交織的天書。

<q>一定是磁碟壞了，</q>一位不願具名的科技考古學家在十年前的會議紀錄中留下這句話，<q>才會把俄語程序顯示成漢字。</q>

另一派學者則持截然相反的看法，並因此引發一場延燒十餘年的學術筆戰。以<u>權慧晶</u>教授為首的一派指出，<u>蘇聯</u>與<u>共產中國</u>之間的關係，或許遠比史書記載的更為曖昧——彼此在意識形態上雖劍拔弩張，私下的技術交流是否完全斷絕，史料從未給出明確答案。程序中摻入中文，或以漢字作為加密手段，並非全無可能。

（編按：此論點目前史學界尚無定論，然而<u>中蘇</u>於一九六九年已爆發邊境武裝衝突，<u>蘇聯</u>更一度評估對<u>中國</u>發動核先制攻擊，學界多數意見認為技術共享可能性極低。該爭論至今仍是考古語言學界著名公案。）

上述爭議，在上月以一種格外令人洩氣的方式畫下句點。

謎底不在磁碟，不在<u>蘇中</u>秘密協議，而在一件所有人都忘了去想的事：編碼。

破譯組的年輕成員<u>循尼亞・薛</u>，在一次例行翻查二十世紀資訊工程文獻時，無意間讀到一份塵封九十年的技術備忘錄，頁首印著<u>蘇聯標準委員會</u>的紅色徽章，內容涉及一套名為<u><code>KOI-8</code></u>的字元編碼規範——專為西里爾字母設計，與當時西方通行的<u><abbr title="American Standard Code for Information Interchange" lang="en">ASCII</abbr></u>系統互不相容，彼此之間無一字母對應。

在此有必要向習慣了萬碼歸一的現代讀者稍作説明。所謂「<dfn>編碼</dfn>」，是電腦將文字轉化為數字訊號時所依據的對照表；而所謂「<dfn>亂碼</dfn>」，是當一份文件用某套對照表寫成，卻被另一套對照表強行解讀時，所產生的荒謬結果——正確的數字，對應到了<em>全然錯誤</em>的文字。這在今日聽來匪夷所思，因為當代通行的<u>Unicode</u>標準已將<u>地球</u>上幾乎所有文字系統收納其中，任何裝置讀取任何文件，皆從同一張總表取字，亂碼作為一種日常災難，早已絕跡逾八十年。然而在二十世紀下半葉，各國、各系統、有時甚至各機構之間，各自維護著一套互不承認的編碼規範，猶如語言相通卻字母各異的平行文明。<q>當時<u>美國</u>的電腦，</q><u>循尼亞・薛</u>在記者會上以平靜得近乎殘忍的語氣説，<q>連『<u><i lang="de">Schrödinger</i></u>』這個名字，當時的電腦都無法完整顯示——那個用來命名核子時代最著名思想實驗的人。整個數位文明在當時其實是各説各話的。</q>

她隨即補充，<u>KOI-8</u>及其同類編碼，在距今約九十年前，已隨著<u>Unicode</u>統一標準的全球普及而悄然退出歷史舞台。近半個世紀以來，人工智慧模型的訓練語料庫中，這類格式的文本已稀少到可以忽略不計。

<q>連電腦也不行，</q>現場待機的人形語言學機器人<u>EISO-2200</u>補充道，措辭一如既往地精確而不帶任何感情色彩，<q>相關訓練資料量不足以令模型辨識這屬於一種系統性的編碼錯誤，而非真實的漢字內容。</q>

換言之：<strong>沒有人讀得懂，是因為所有人用的都是錯誤的鑰匙</strong>。正確的解法，是以<u><code>KOI-8</code></u>格式重新讀取磁碟，再轉換為當代<u>Unicode</u>標準。整個過程耗時約<em>十七分鐘</em>。而這個方法，在一百年前本是任何一名資訊工程學生入學第一週便會習得的常識——只是那門課，早已從所有大學的課綱裡消失。

破譯組事後表示，正確版本的程序以標準俄語寫成，技術邏輯清晰，保存狀態完好，並無任何損毀或加密跡象。

據悉，拆除作業將於下周正式啟動。這批飛彈內部的<ruby class="zhuyin">鈽<rt>ㄅㄨˋ</rt></ruby>與鈾-235，將統一移送至<u>非洲超導電池聯合工廠</u>，降濃縮處理後製成民用儲能電芯，首批成品預定免費配發予<u>月球</u>定居點及<u>南極洲</u>越冬站居民，作為取暖設備電源。

一個半世紀前凝固的末日預言，以這樣的方式抵達它最終的去處：某戶人家的暖氣，在極夜裡亮著。

<u>循尼亞・薛</u>離開記者台前，有人在人群中喊了一句：<q>那十五年呢？</q>

她停頓了一秒。

<q>那十五年，</q>她説，<q>是我們為不記得歷史所付的<em>學費</em>。</q>

掌聲沒有響起。
