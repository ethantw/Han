標點擠壓
與懸掛

中文標點不是一格又一格互不相干的方塊。Han.css 依相鄰關係收緊空白、修整行首， 並讓句讀懸出行尾；這份樣張把原始排版、擠壓與完整自動模式放在同一頁比較。

01 / GRID 一條淡線，就是一個全形字格

觀察兩枚標點合計占一格、一道半，或維持完整兩格。

02 / EDGE 紅線標示實際欄尾

開括號貼齊行首；可懸掛的逗號、句號則越過欄尾。

03 / FONT DTJ 提供四套標點

切換 MOE、JIS、GB、KLR，橫排與直排都使用真正的標點字形。

Browser / live comparison

三種處理，逐格對照

左欄保留瀏覽器原貌，中欄只處理相鄰標點，右欄再加入行首修整與行尾懸掛。控制台會同步切換三欄。

01 / none

原始排版

不建立標點 wrapper，保留瀏覽器與字體本身的配置。

02 / compress

標點擠壓

依標點組合縮減字格，不啟用句讀的行尾懸掛。

03 / auto

完整自動模式

偵測原生能力，補齊擠壓、行首修整與行尾懸掛。

Node.js / SSR-preprocessed HTML

先排好，再交給瀏覽器

同一套 Han.js 也能在 Node.js 執行。這一段在產生頁面時已經處理完成，瀏覽器端不會再次改寫它。
