破折號熔接——兩截該接上的線

中間斷開的破折號，起自 Unicode 共用碼位的歷史問題，透過 OpenType ＋ CSS unicode-range 字體技術，精準為讀者拂偏歸正。

為什麼會斷開

出在 CSS 的 fallback 順序。大家習慣把西文字體寫在前、漢字字體寫在後，而 U+2014 是中西共用碼位、西文字體都收——於是中文文章裡的破折號由西文字體回答。西文又偏好兩端稍微不碰字框邊界的破折號（Georgia 兩側各留 0.05 em、Helvetica Neue 各留 0.13 em），兩個並排，中間就開一道縫。

這不是漢字字體的錯：CJK 字體的 emdash 普遍貼齊字框兩緣，Noto CJK 甚至自帶 ccmp 連字，直接把兩個 emdash 熔成一個字符。問題純粹是這個碼位被誰接走了——所以修法也在那裡：unicode-range 只認約 30 個標點碼位，把標點槽插到西文字體之前，碼位一回來，連字就開火。

對照：同一段字，差別只有一層字體槽

與專名號互為鏡像

這張圖的幾何跟首頁站③ MarkDiagram 專名號那一列是同一個：一對相鄰的線段，靠中縫開合。但兩者要的答案剛好相反——專名號的兩截必須斷開，兩個相鄰的專名要看得出是兩個；破折號的兩截必須接上，—— 是一根線而不是兩根。

同一個動作，兩個相反的正確答案。標點的對錯從來不是幾何問題，是慣例問題——這也就是標點該有自己的字體槽的理由。
