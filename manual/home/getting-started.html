壹·零·零・GETTING STARTED

三步即用，立得其所

無build step、只有一個外部依賴函數庫。一條npm指令，或一個CDN連結，皆可立即接入。

完整安裝文檔 → 框架原理 → 逐步範例 →
壹

安裝

$ npm install han-css
CDN
直接<link>引入jsDelivr / unpkg上的最新版亦可。
貳

引入

// 1) link the stylesheet
<link rel="stylesheet" href="han.css">

// 2) load the module
<script type="module" src="han.js"></script>
參

標記

<article class="han">
  <h1>東京晴空塔</h1>
  <p>此塔座落於…。</p>
</article>
TIP
添加class="han"即可啓用全部排版規則。
