## 一、時空觀：柯南法則

**報紙永遠是一百年後的今天。** 打開的那一刻，報頭日期就是讀者現實時間加一百年，Masthead 的 JS 已實作此邏輯。

**絕對禁止在文章中點名公元年份。** 一旦寫死「二一二六年」，柯南法則即告破功。所有時間表述一律用相對語言：

| 參照 | 寫法 |
|------|------|
| 報紙當下 | 今日、本月、昨日、日前 |
| 報紙的過去 | 八十年前、數十年來、上月、去年 |
| 讀者視角的近未來 | （不寫，報紙本身即已是未來） |

> **計算方法**：以「今天+n年」或「今天+100-n年」靈活換算，選哪種取決於哪種表述對報導最有時間感。例：《人機婚姻平權法》通過於今天+9年、即報紙的91年前；「冬眠船出發後第47年」是文章本身交代的計算起點，直接保留。

例外：2026年以前的真實歷史事件可直接寫年分，如：2001年的九一一事件、1945年台灣光復、1446年《訓民正音》出版等。

## 二、報頭紀年格式

報紙採**中華民國紀年**，搭配偽日本天皇年號：

```
民國二百一十五年　公元2126年・弘宙元年
```

- **民國年**：讀者現實年份的民國紀年 + 100（當下若為民國115年，報紙即民國215年）
- **公元**：同上，讀者現實年份的公元紀年 + 100
- **弘宙**：虛構日本天皇年號，固定為「弘宙元年」（不隨文章更換）——**報紙永遠停在改元的第一年**，天皇永遠是剛上任的那一位

### 皇室設定（因「元年」而來，涉皇室者一律遵守）

今上天皇**明子天皇**於本年踐祚、改元弘宙，即位大典已於報紙時間的日前舉行（見
`emperor-enthronement`）。由此推出的硬約束：

- 一切皇室報導都在「踐祚未滿一年」的框架內。不可寫「在位多年」「歷年慣例」之類。
- **今上為女帝，而報導絕不就此發表任何意見。** 女性繼位在此世界早已是舊聞，沒有「首位」
  「破例」「歷史性一刻」之類的字眼，一個都不准出現——不評論，就是這則設定的全部笑點。
  （寫實理由：現實世界隨時可能通過女性繼位法，任何「第一位」的說法都會過期。）
- **配偶為男性，稱號「皇配」**，絕不可寫成「皇后」。名銜之爭**不是「無先例」，而是先例
  太多**——皇婿、皇夫、皇配、王配四個都能用，宮內廳議卅一日，比年號多議十二日，結論是
  四個都能用。
- 皇配**金賢宇**，平壤人，白磁匠人，家傳窯場訂單排至百年後；其族譜載十四代祖於1592年
  被擄往日本，後裔一支數代後渡海而返，輾轉落腳平壤。**此事平鋪直敘，絕不解釋。**
- 前代年號**豐洋**，前天皇讓位為**上皇**，在位卅餘年。
- 弘宙出典《淮南子・齊俗訓》「往古來今謂之宙」。有識者會議的爭點**不在漢籍或和書**（那
  種爭論早就沒人在吵了），而在**年號可不可以用一個講外太空的字**——守舊派認為年號當言
  治世之德，「宙」是地理名詞，而且是別的地方的地理。主張派的理由只有一句，逐字收錄於
  會議紀錄：**「絕大多數國民已經不住在這座列島上了。」** 這是本設定的核心台詞。
- 宮內廳內規：**皇位繼承順位前三者不得搭乘瞬移艙**（不接受原子重組）。上皇退位後始
  解禁。皇室出行因此只能用超迴路或亞軌道跳躍，可作為行程報導的隱藏笑點。
- 三語名稱對照：ZH 明子天皇／皇配金賢宇；JA 明子(あきこ)天皇／皇配(こうはい)キム・
  ヒョヌ（金賢宇）；KO 아키코 덴노／`<ruby>皇配<rt>황배</rt></ruby>` `<ruby>金賢宇<rt>김현우</rt></ruby>`
  （日本人名用日語音譯 한글，朝鮮半島人名用漢字＋漢字音 ruby）

### 科技水平

- **地面交通**：四種運具分工明確，**不可互相取代**——
  - **超迴路**：真空管幹線，全球二百八十餘城（亞洲八十餘城通車、一百二十城在建）。最快、運量最大、班次密（都會區間每三分鐘一班，發車前三十秒抵站仍可登車，無須前置）。缺點：只停幹線大城，需減速弧與客流
  - **瞬移艙**：前代技術，相位置換。移轉本身十七秒且與距離無關，但**實際時間全花在「原子核對」**——須逐一驗算乘客身上七千兆兆個原子確實送達，算力昂貴。限制：①僅限地球磁層內（跨球一律不可）②高輻射地區配額少或禁設 ③全球僅十七座核對中心，條約凍結、無法增設 ④**購票須提前五小時**（法定最短前置，因排程本身要算五小時；常態通勤者用「月配窗口」）⑤每艙六人上限、**不承運大宗貨物** ⑥衣物行李列「附屬質量」，有極低機率損壞遺失 ⑦無生理風險，但約2.3%的人有「重組疑慮」心理障礙。優點：目的地一萬四千二百餘處、票價最低、無體感不適
  - **亞軌道跳躍**：電磁彈射＋彈道飛行，任兩座跳躍場一百分鐘內可達。全球僅十四座跑道（需連續四公里、水平公差七毫米）。四倍重力＋失重＋緩降下墜感，初次嘔吐率31.4%。運能極小。已成偏遠地區居民的炫耀式交通
  - **環球鐵路**：更早世代的實體軌道全球網，最慢、最便宜、沿途各站可上下，**仍是全球物流主體**，客運已轉觀光取向
  - 記憶點：**超迴路是隨到隨走的日常；瞬移艙是預約制、去所有沒人要去的地方、且只在地球上；跳躍機是給連瞬移艙窗口都排不到的人；環球鐵路載貨**
- **太空交通**：地月太空電梯「天柱一號」（隨到隨搭，地鐵感）；艙體仍有約27%機率引發「球際高山症」
- **醫療**：IBS-9型球際AI全身掃描，20–40分鐘，偵測至0.2mm腫瘤；費用由聯合球際衛生組織補貼，近乎免費；副產品：健康旅遊成新興產業
- **境管**：「隔離購物中心」——進商場掃描、領報告、通關，拒入境率僅0.0002%（幾乎等於被救一命）
- **通訊**：**兩套系統，別搞混**——
  - **神經共振晶片**＝**近距離**生物間意念交換，作用範圍以公尺計，就是「同處一室不必開口」的
    通心術。三體殖民地90%居民已植入；返回地球後常出現「地球溝通不適應症」。
    **絕不可拿來做遠距／跨星傳訊。**
  - **地球本土植入率僅千分之四**——地球人有自己的禮儀與說話方式（説白了就是說謊），通心術
    太赤裸，接受度極低。官方問卷的拒絕理由前三名：「不想被知道我在想什麼」／「不想知道別人
    在想什麼」／「講話本來就不是為了傳遞內容」。地球確有神經共振愛好者社群（約十一萬人），
    但守則第一條是**日常一律關閉、聚會時方才開啟**，且守則不說明理由。
    **理由永遠不寫出來**，要讓讀者自己想到「怕太傷人的話被偷聽」。
  - **智子**＝跨星系即時傳訊，不受距離與光速限制，影像、文字、轉播都走這條。三體與地球
    日常互通即靠它：三體職棒經智子轉播回地球極受歡迎，已有地球選手受邀加入三體球隊
    （人得搭船，四年餘方至；比賽卻早就看完了）。
  - 由此生出的常備笑點：**官方儀典仍規定影像須以光速傳播**（儀式神聖性所繫），而所有人
    早就用智子看過了。兩件事並存，各方一律不置可否。
- **AI**：全面滲透研究、醫療、新聞、外送與創意產業；可獨立主導研究、生成論文，也可擔任商業空間的美術設計、品牌與企畫主責，但訓練資料的時效性仍是弱點（見「編碼知識衰退」）
- **太空採礦**：歐羅巴殖民地深海採礦機器人常規作業

### 社會生活與公共文字

- **中國大陸已恢復以繁體字作為公共文字**：商場招牌、交通導視、官方紀錄與日常介面自然使用繁體字。報導不得把此事寫成新聞、復興運動或政治表態；與女性天皇相同，眾人不加解釋地照常使用，設定才成立。
- **日常手寫近乎消失**：除書法家、歷史技藝從業者及少量紙本簽收事故外，一般人甚少提筆書寫，對手寫筆勢已無身體直覺。人們仍大量閱讀漢字，只是不再藉由手部動作理解字形。
- **二十一世紀已成復古消費題材**：後人會把智慧型手機殼、無線耳機充電盒、掃碼點餐、手動摺疊購物袋等相隔數十年的日用品，壓縮成同一種「廿一世紀風格」。報導不必指出年代混搭，讓分類本身成為笑點。
- **城市末端交通全面自動化**：市區巴士、通勤艙、物流車與配送機器人皆可由中央系統協調，自動避障通常不會傷人；事故的主要不可預測因素往往是人類注意力。此設定只補充市區末端交通，不取代超迴路、瞬移艙、亞軌道跳躍與環球鐵路的既有分工。

### 婚姻與身份法律

- 人機通婚合法已91年；人形機器人工會有完整法律地位
- 獸機（住在獸型殼體的完全自主AI）通婚目前立法辯論中，反對最力者恰為已享有婚姻權的人形機器人工會（視為「外殼歧視」問題）

## 四、經濟與物價世界觀

### 房地產崩解

超迴路兩小時通勤圈 + 邊境全面取消 → 任何人可住在任何地方（南北極、海底、月球、太空站），住所不再稀缺。**房地產已非投資標的**，地段溢價趨近消失。

### 新貴重物

| 類別 | 例子 |
|------|------|
| 重金屬礦產 | 鈦礦、稀土（歐羅巴採礦公司股票火熱） |
| 軌道公司股票 | 月球旅館概念股六十年漲逾六百個百分點 |
| 極細人工技藝 | 機器人無法複製的手工（如赫珊師傅手織四十一天的克非葉）；此類訂單排至百年後 |

### 信用點物價

有些東西看起來（跟今天比）**異常便宜**，有些**異常昂貴**。報導不解釋，讓讀者自己感到奇怪。

> 例：超迴路延誤賠5信用點（約合今日新台幣0.03元）；一份全身AI掃描幾乎免費；但礦物期貨或某藝匠預約可能值天文數字的信用點。

## 五、文字技術知識衰退（Unicode與字形考古笑點）

### 「國字標準形體」只存在於報導世界

未來報導將現實中的「國字標準字體」稱為**「國字標準形體」**。這是報導世界內沿用的
虛構名稱，性質與「蕉黑」相同，只能出現在 `zh/`、`ja/`、`ko/` 報導及其首頁節錄中。
專案文件、編輯備忘與一般文案談論現實概念時，仍一律使用**「國字標準字體」**。不可因
修改報導而全庫搜換，也不可在報導內解釋兩者的對應關係。

`standard-glyph-revival` 從歷史壓縮檔找回的三套字體固定為**「蕉黑-繁」**、
**「辛石多口體503」**、**「巨硬賈黑體」**；「國字標準形體」則是三者説明所稱的共同規範。
這四個名稱都屬報導世界，公開報導只把它們當作普通名稱使用，**不得解釋諧音、拆字、版本號
或現實原型**，讓讀者自行發現彩蛋。跨語版本可依各語正字與字體慣例調整字形，但不得另造
第四套字體或改變三者的身分。

今天的專業人士對 Unicode、KOI-8 等編碼有深入認識。一百年後，相關知識因：
- 訓練資料庫清洗時被歸類為「技術性歷史文件」而稀釋
- 機器人和AI系統長期在 UTF-8 環境下運作，認為「字就是字」
- 人類從業者已多代未遇真實編碼衝突

導致的結果：**連政府系統或AI都可能因編碼處理粗糙而鬧笑話**——從今天讀者的視角看來，這是理所當然的基礎知識；從報紙角度，卻是「調查報導」層級的科技考古。

同一斷層也發生於**印刷字形、古代字體與手寫規範**：某套技術或規範若因問題消失太久，後人可能只在未分類完善的教育史資料庫或「傳統文化資產」壓縮檔中重新發現，並把「符合標準」「年代久遠」誤當成品質認證。此類報導應指出具體部件、筆畫或排版後果，不以抽象的「古今審美不同」帶過。

> 參考：`soviet-koi8-nuke` 文章——當年蘇聯核武解除系統因 KOI-8 被遺忘而無法執行，以「這個名字連電腦都顯示不了」（Schrödinger）為例，說明編碼斷層如何具體影響歷史進程。

## 七、全語種排版規範

### 漢字與拉丁文間距

中文、日文報導中，漢字（含假名）與西文字母、阿拉伯數字之間**不加手動空格**，由 CSS `text-autospace` 統一渲染間距。韓文依 KO 書寫慣例（KO 中西文單詞前後通常保留一個半形空格）。

### 間隔號

統一使用「**・**」（U+30FB，片假名中點），不用「**·**」（U+00B7，拉丁中點）。

> ✓ 太平洋版・晨刊　✓ 公元21xx年・弘宙元年
> ✗ 太平洋版·晨刊

### 簡體中文版規範

簡體版統一在 SSR 或 API 階段由繁體版自動轉換，**不在原始資料中維護獨立簡體版本**。轉換規則：

- **只做繁→簡字形轉換**，詞彙一律保持原狀，不做地區詞彙替換
  - 螢幕 → 荧幕（字形轉換）✓，不改為屏幕（地區詞）✗
  - 軟體 → 软体 ✓，不改為软件 ✗
- **引號**：統一保留直角引號「」『』，不轉換為彎引號 "" ''
- **間隔號**：統一保留全形「・」，不轉換為其他符號

## 八、中文（ZH）寫作風格

### 文體

現代白話報章文體，夾帶文言點睛。整體是「正式、嚴肅」的新聞語調，幽默靠荒謬細節自然流露，**不靠描述笑點，笑點在字裡行間自炸**。

### 文言用法（節制使用，畫龍點睛）

| 白話 | 文言替換 | 例句 |
|------|----------|------|
| 三十 | 卅 | 行之卅餘年 |
| 剛剛 | 甫 | 本月甫通過 |
| 可能 | 或 | 或成可能 |
| 在 | 於 | 昨日於日內瓦第七和平宮…… |
| 為了什麼 | 以…為 | 以生食聞名於世 |

數字書寫：重要歷史數字或特別精確的計數用繁體中文（一萬〇九百二十三國）；一般語境可用阿拉伯數字（17秒、0.0002%）。**年份絕不寫成「二一二六年」等絕對公元年份**（柯南法則）。

### 標題格式

多段式，以全形空格（　）分隔，常包含：事件主句 + 引號直接語氣 + 反差結語。
> 「百年流浪旅行冬眠途中醒來　原因：太能喝酒　AI 算錯麻醉劑量　聯邦賠一百點（合新台幣一點四三元）」

### 電頭格式

```
【本報某某特派員　李明遠　專電】
【本報地月特派員　張子維　日內瓦─月城連線報導】
【本報某某站直擊】
```

### 編按格式

```
（編按：「…」為…之傳統環節，…。本屆…——…，消息一出，已在各方觀察員間引發廣泛討論。）
```
置於相關段落下方，獨立段落，括號包住全文。

### 幽默手法（這是風格核心）

1. **細節過度精確**：咀嚼二十二秒（多家媒體交叉計時為證）；凌晨三點十四分；AI 辨識出一萬五千九百四十八種「歡愉表情」
2. **荒謬職稱，一本正經**：食安沙皇、生食翻譯官、「官銜為『生食翻譯官』之專員」
3. **渺小補償，莊嚴告知**：聯邦賠一百點（合新台幣一點四三元）；補償五信用點（約合新台幣零點零三元）
4. **官僚廢話被直接引用**：「在一個你出不去的地方，談自由選擇，很有趣。」
5. **史詩敘事寫雞毛小事**：三分鐘延誤寫成「舉國譁然」
6. **溫柔私密時刻與宏大政治並置**：峰會桌上，兩個丈夫交握的手；海膽，他們都不吃
7. **結尾留懸念或哲學句**：「她說：『一個更好的購物中心。』全場再度笑聲。但沒有人確定，她是否在開玩笑。」

## 九、日文（JA）寫作風格

### 文體

**である体**（文語的・報章的非敬語形）。動詞・形容詞・名詞述語一律以「…である」「…だった」「…た」結尾，不用「…ます」「…です」。

### 振假名規則

**只給高中生難以輕鬆認識的漢字注音**：

| 標注 | 不標注 |
|------|--------|
| 咀嚼(そしゃく)、嚥下(えんげ) | 大統領、外交、記者 |
| 代物(しろもの)、昼餐会(ちゅうさんかい) | 刺身、握り寿司 |
| 雲丹(うに)、本鮪(ほんまぐろ)、鰤(ぶり) | 魚、海、水 |
| 沙皇(ツァーリ)、主厨(しゅちゅう) ← 外来語読み | 研究、報告 |
| 官腔(かんくう)、淡然(たんぜん) ← 文語 | 国際、発言 |
| 華語(かご)、交叉(こうさ) ← 中国語由来 | 会議、政治 |
| 睦まじさ(むつまじさ)、居住まい(いずまい) ← 訓読み難語 | |
| 強張らせた(こわばらせた)、掻き消す(かきけす) ← 複合動詞 | |
| 長嘆息(ちょうたんそく)、鮭子(いくら) | |

漢字由来の外来語には**カタカナ読み**を振る：`<ruby>沙皇<rt>ツァーリ</rt></ruby>`、`<ruby>厨道輪席宴<rt>ちゅうどうりんせきえん</rt></ruby>`

地名：本文では「日内瓦」（漢字形）を使用。初出では `<ruby>日内瓦<rt>ジュネーブ</rt></ruby>` で読みを提供。

### 編集注格式

```
（編集注：「<ruby>厨道輪席宴<rt>ちゅうどうりんせきえん</rt></ruby>」は、…三十余年にわたり受け継いできた伝統的な<ruby>催し<rt>もよおし</rt></ruby>である。…。）
```

## 十、韓文（KO）寫作風格

### 文體

**漢諺混寫體** + **해라체**（格式體平語）

- **漢諺混寫體**：모든 漢字語 내용어를 `<ruby>漢字<rt>독음</rt></ruby>`로 쓴다
- **해라체**：신문・문어체 문말어미（이었다、했다、말했다、것이었다）。경어（습니다、요）불사용

### 인용 부호 내 체태

지문（地の文）은 해라체 고정. 「」 안의 직접 화법은 **화자・청자의 관계**에 따라 적절한 체태를 선택한다.

| 상황 | 체태 | 예 |
|------|------|----|
| 공식 발언（기자회견・연설・공식 답변）| 합쇼체 | 「맛있습니다！」 |
| 직급 차이가 있는 업무 대화 | 합쇼체 또는 해요체 | 「그렇게 하겠습니다」 |
| 사적・친밀한 장면 | 해요체 또는 해라체 | 「맛있어！」 |
| 동료・친구・가족（대등・하대） | 해라체（반말） | 「맛있다！」 |

> 예：대통령이 기자에게 → 합쇼체 / 대통령이 배우자에게 사적으로 → 해라체（반말）

### 漢諺混寫 適用規則

| 類型 | 處理方式 |
|------|----------|
| 漢字語 내용어 | `<ruby>大統領<rt>대통령</rt></ruby>` |
| 純한국어 | 한글만（아버지, 하다, 가다, 어미）|
| 直接引用 | 한글만（「괜찮네」, 「맛있다」）|
| 아라비아 숫자 | 22초, 30분, 60여 년（한자 불사용）|
| 외래어 고유명사 | 한글（트럼프, 카림, 할랄, حلال）|
| 복합어 | 각 형태소별 독립 `<ruby>` 태그 |
| 카테고리 태그 | 漢諺混寫（`<ruby>國際<rt>국제</rt></ruby> 뉴스`）|

### 中文固有名詞的讀音——韓語漢字音原則

中文地名、人名譯入韓文時，**一律採韓語漢字音（한국 한자음）**，不可採現代國語（普通話）發音的音譯。中文固有名詞屬漢字語，套用漢諺混寫規則：漢字本體＋漢字音 ruby。

- ✅ `<ruby>台北<rt>대북</rt></ruby>`（韓語圈歷史慣用音：臺=대，如 대북시）　❌ 타이베이
- ✅ `<ruby>北京<rt>북경</rt></ruby>`　❌ 베이징
- 例外：**本非中文的人名**（俄、西方人名，即便報導中文版寫作漢字，如 謝廖沙・林）不在此列，照外來語規則用 한글 音譯原語（세료샤 림、트럼프）。

**檢査方式**（機械可驗）：

1. **一個漢字恰對應一個諺文音節**。一字膨脹成兩個音節（台→타이、北→베이）即是誤用國語音。
2. **入聲漢字帶終聲收尾**——中古漢語 -p／-t／-k 韻尾在韓語漢字音保留為 ㅂ／ㄹ／ㄱ 終聲（北→북、十→십、一→일；-t 規則性變 ㄹ，標準漢字音無 ㄷ 終聲，除非該詞慣例上真有）。國語音譯裡入聲蕩然無存，是第二個判別訊號。

多音字（台=태／대 之類）取**韓語圈對該名詞的歷史慣用音**，非逐字査字典自組；拿不準時依 ruby-markup Rule 5 flag 給 operator，不可默默自選。

### 전문 예시

```
<ruby>大統領<rt>대통령</rt></ruby>은 몸을 기울여 나직이 중얼거렸다.
이 말은 <ruby>補佐陣<rt>보좌진</rt></ruby>이 아니라 남편을 향한 것이었다.
「당신은 진작 알고 있었지」라고 말했다.
```

직접화법 인용 패턴：**「…」라고 말했다** / 「…」고 했다（간접화법도 가능）

### 전보 형식

```
【<ruby>本紙<rt>본지</rt></ruby> 제네바 <ruby>特派員<rt>특파원</rt></ruby> 이명원 <ruby>電傳<rt>전전</rt></ruby>】
```

### 編輯注 형식

```
（<ruby>編輯<rt>편집</rt></ruby> <ruby>注<rt>주</rt></ruby>：「<ruby>廚道輪席宴<rt>주도윤석연</rt></ruby>」은 …30여 년간 이어 온 <ruby>傳統<rt>전통</rt></ruby> <ruby>行事<rt>행사</rt></ruby>로, …이다.）
```
본문 전체를 漢諺混寫體로 유지.

## 十二、維基條目文體（非新聞）

**作用域**：`wiki/<lang>/` 下的虛構百科條目。與報導同一世界觀、同一排版規範，但**文體完全不同**——條目不是報導，沒有電頭、沒有特派員、沒有現場描寫。

### 紀年

**柯南法則同樣適用**：條目內不寫絕對年份，一律相對說法（「六年前」「逾四十年」「其後兩年」）。百科體例本偏好確切年代，此處刻意不給。**暫不為維基另立紀元。**

### 文體

中性百科體、多用被動與無主語句。慣用句式：「須注意者」「一般而言」「多數研究認為」「相關研究已停滯逾X年」。幽默**只能**靠所述事實本身的荒謬，語氣必須始終平板——報導可以有記者的眼睛，條目不可以。

### 結構模板

```
導言（定義＋一句話講出核心矛盾）
名稱（俗稱／正式名／業界內部稱法；命名誤解是好素材）
原理
（分項細節：運能、覆蓋、安全…）
與其他X之比較（表格）
產業狀況
爭議
文化影響（俗語、標籤、社群現象）
參見（純文字條目名，不用連結語法）
```

### 維護模板

條目開頭可掛引用區塊模板，是本文體的專屬笑點來源：

```
> **本條目部分內容需要更新。**最後一次全面校訂於六年前……
> **本條目之「X」章節可能過度側重使用者觀感。**討論頁已就此爭論四年。
```

### 自我指涉手法（可重複使用）

- **過時但刪不掉的句子**：「本條目最常被引用之句子出自其早期版本，至今未被刪除」／「該句已不符現況，惟四度刪除皆遭回退」。
- **停滯的研究**：「相關研究已停滯逾四十年，主流意見認為此問題『已不具工程意義』」。
- **編輯戰的年數**：爭議的長度用年計，且不說結果。

### 排版

同報導：全形標點、間隔號用「・」、漢字與西文數字間不加手動空格。

### 禁忌

- 不用第一人稱、不寫「我們」、不對讀者說話
- 不出現電頭、記者、受訪者現場反應（受訪引語可出現於「爭議」節，但須以第三人稱間接引述框住）
- 不解釋笑點——與報導同一條鐵律

## 十三、禁忌與注意事項

- **絕不寫死公元年份**：「二一二六年」一旦出現，柯南法則破功
- **不要解釋笑點**：荒謬細節直接平鋪，不加「這令人發笑因為……」
- **不要解釋物價邏輯**：某東西異常便宜或異常昂貴，報導不說明原因，留給讀者自己奇怪
- **不要破壞文體一致性**：KO 中不可出現未加 ruby 的漢字語；JA 中不可混入 ます/です
- **ZH 文言不要過量**：一段最多一兩個文言用詞，大量文言會破壞白話報章感
- **數字精確度是笑點**：勿四捨五入「三分鐘延誤」或「二十二秒」——精確度本身是喜劇
- **政治人物設定**：川普總統是真誠、笨拙但溫柔的人物，不要寫成反派；卡里姆是真正的核心人物
- **科幻設定是背景，不是主題**：技術細節用來製造荒謬感，不要花篇幅解釋技術原理
- **編碼笑點不要說教**：KOI-8 / Unicode 知識衰退的諷刺留給讀者去懂，報導本身保持嚴肅記者口吻
- **弘宙元年就是今年**：涉皇室者一律以「新帝踐祚未滿一年」為前提。凡「在位多年」「歷屆
  皇室慣例」「今上素來如何」之類的寫法都與元年相牴觸——新天皇還沒有「素來」
